1) PIPELINE CART-SERVICE
================================================================

1.1. Cấu hình Docker Compose
-----------------------------

- File: `docker-compose.yml`
- Service:

  cart-service:
    build: ./cart-service
    ports:
      - "8003:8000"
    environment:
      - DB_HOST=host.docker.internal
      - DB_PORT=5432
      - DB_USER=postgres
      - DB_PASSWORD=1234
      - DB_NAME=bookstore_cart
      - REDIS_HOST=redis

Ý nghĩa:
- Image được build từ thư mục `./cart-service/`.
- Sử dụng PostgreSQL database `bookstore_cart` ở chế độ Docker.
- Khởi chạy Redis background consumer thread để lắng nghe sự kiện từ `user-service`.

1.2. API chính của cart-service
-------------------------------

- Path: `cart-service/cart_service/urls.py`
  - POST  `/carts/`                          -> tạo Cart
  - POST  `/carts/add-item/`                 -> thêm item vào giỏ hàng (check book qua product-service)
  - GET   `/carts/<customer_id>/`            -> xem chi tiết giỏ hàng theo customer_id
  - GET   `/carts/customer/<customer_id>/`   -> lấy thông tin cart object

2) PIPELINE PAYMENT-SERVICE
================================================================

2.1. Cấu hình Docker Compose
----------------------------

- File: `docker-compose.yml`
- Service:

  payment-service:
    build: ./payment-service
    ports:
      - "8007:8000"
    environment:
      - DB_HOST=host.docker.internal
      - DB_PORT=5432
      - DB_USER=postgres
      - DB_PASSWORD=1234
      - DB_NAME=bookstore_payment
      - REDIS_HOST=redis

Ý nghĩa:
- Image build từ `./payment-service/`.
- Dữ liệu giao dịch được lưu trữ trong database PostgreSQL `bookstore_payment`.
- Tích hợp Redis Event Broker để phát đi thông điệp thanh toán hoàn tất.

2.2. API chính của payment-service
----------------------------------

- Path: `payment-service/pay_service/urls.py`
  - GET   `/payments/`                       -> xem toàn bộ danh sách thanh toán
  - POST  `/payments/create/`                -> tạo giao dịch thanh toán
  - GET   `/payments/<payment_id>/`          -> chi tiết một payment
  - PATCH `/payments/<payment_id>/status/`   -> cập nhật trạng thái thanh toán (phát event payment_processed)
  - GET   `/payments/order/<order_id>/`      -> payments theo mã đơn hàng
  - GET   `/payments/customer/<customer_id>/`-> payments theo mã khách hàng

3) LUỒNG SEQUENCE DIAGRAM CHÍNH
================================================================

3.1. Đăng ký khách hàng -> Tự động khởi tạo giỏ hàng trống (Redis Pub/Sub)
--------------------------------------------------------------------------

```mermaid
sequenceDiagram
  autonumber
  actor User as Khách hàng
  participant UI as frontend (UI)
  participant UserSvc as user-service
  participant Redis as Redis Broker
  participant CartSvc as cart-service
  participant DbCart as DB Cart (PostgreSQL)

  User->>UI: Thực hiện Đăng ký tài khoản
  UI->>UserSvc: POST /customers/ {name, email, password}
  UserSvc->>UserSvc: Tạo tài khoản & lưu vào MySQL
  UserSvc->>Redis: Publish event "customer_created" {customer_id, email, name}
  UserSvc-->>UI: 201 Created (Tài khoản hoạt động)
  UI-->>User: Đăng nhập thành công

  %% Background process
  Redis-.->>CartSvc: Consumer nhận event "customer_created"
  CartSvc->>DbCart: Khởi tạo giỏ hàng mới cho customer_id
```

3.2. Cập nhật trạng thái thanh toán -> Tự động xác nhận đơn hàng (Redis Pub/Sub)
--------------------------------------------------------------------------------

```mermaid
sequenceDiagram
  autonumber
  actor Admin as Admin / Staff
  participant UI as frontend (Admin UI)
  participant PaySvc as payment-service
  participant Redis as Redis Broker
  participant OrderSvc as order-service
  participant NotiSvc as notification-service
  participant DbOrder as DB Order (PostgreSQL)

  Admin->>UI: Đánh dấu hóa đơn đã thanh toán ("paid")
  UI->>PaySvc: PATCH /payments/<id>/status/ {status: "paid"}
  PaySvc->>PaySvc: Lưu trạng thái "paid" vào PostgreSQL
  PaySvc->>Redis: Publish event "payment_processed" {order_id, customer_id, amount, status: "paid"}
  PaySvc-->>UI: 200 OK (Thanh toán hoàn tất)

  %% Consumers
  Redis-.->>OrderSvc: Consumer nhận event "payment_processed"
  OrderSvc->>DbOrder: UPDATE Order WHERE id=order_id SET status="confirmed"
  
  Redis-.->>NotiSvc: Consumer nhận event "payment_processed"
  NotiSvc->>NotiSvc: Tạo nhật ký thông báo thanh toán thành công cho khách hàng
```
