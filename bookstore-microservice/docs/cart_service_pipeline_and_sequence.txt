================================================================
1) PIPELINE (các bước triển khai / chạy cart-service)
================================================================

Mục tiêu:
- Build và chạy riêng `cart-service` hoặc chạy cùng toàn bộ hệ thống bằng Docker Compose.
- `cart-service` cung cấp API giỏ hàng và sử dụng cơ chế lắng nghe sự kiện bất đồng bộ qua Redis để tự động khởi tạo giỏ hàng cho khách hàng mới.

---------------------------------------------------------------
1.1. Vị trí cấu hình trong dự án
---------------------------------------------------------------

- docker-compose:
  - Path: `docker-compose.yml`
  - Service:
    - `cart-service`
      - build: `./cart-service`
      - ports: `8003:8000`
      - environment:
        - DB_HOST=host.docker.internal
        - DB_PORT=5432
        - DB_USER=postgres
        - DB_PASSWORD=1234
        - DB_NAME=bookstore_cart
        - REDIS_HOST=redis
      - depends_on:
        - redis

Ý nghĩa:
- Container lắng nghe port 8000, máy host map ra 8003.
- Dữ liệu được lưu trữ trong database PostgreSQL `bookstore_cart`.
- Kết nối tới Redis container để lắng nghe/gửi thông điệp Pub/Sub.

---------------------------------------------------------------
1.2. Pipeline build/run (Docker)
---------------------------------------------------------------

Chạy toàn bộ hệ thống (khuyến nghị để có Redis Message Broker):
  docker compose up --build -d

---------------------------------------------------------------
1.3. Startup pipeline bên trong container (Dockerfile CMD)
---------------------------------------------------------------

- Path: `cart-service/Dockerfile`
- CMD đang chạy chuỗi lệnh:
  mkdir -p data && python manage.py makemigrations app && python manage.py migrate && python manage.py runserver 0.0.0.0:8000

Ý nghĩa:
- Tạo migrations cho app `app` và migrate database PostgreSQL.
- Chạy Django server trên 0.0.0.0:8000.
- `apps.py` tự động khởi chạy một daemon thread `start_consumer(handlers)` để subscribe kênh Redis.

---------------------------------------------------------------
1.4. API endpoints của cart-service
---------------------------------------------------------------

- Path: `cart-service/cart_service/urls.py`
- Các endpoint:
  - POST  `/carts/`                  -> tạo cart
  - POST  `/carts/add-item/`         -> thêm item vào cart (kiểm tra book qua product-service)
  - GET   `/carts/<customer_id>/`    -> xem item trong cart theo customer_id
  - GET   `/carts/customer/<customer_id>/` -> lấy thông tin cart (bao gồm cart id) theo customer_id

---------------------------------------------------------------
1.5. Model dữ liệu
---------------------------------------------------------------

- Path: `cart-service/app/models.py`
- Models:
  - Cart(customer_id)
  - CartItem(cart FK -> Cart, book_id, quantity)

2) SEQUENCE DIAGRAM — QUÁ TRÌNH TẠO CART BẤT ĐỒNG BỘ
================================================================

Khi một khách hàng đăng ký thành công qua `user-service`, quá trình tạo giỏ hàng sẽ diễn ra bất đồng bộ thông qua Redis Broker để giảm thiểu coupling chéo.

```mermaid
sequenceDiagram
  autonumber
  actor User as User (Browser)
  participant UI as frontend (UI)
  participant UserSvc as user-service
  participant Redis as Redis Broker
  participant CartSvc as cart-service
  participant DbUser as DB User (MySQL)
  participant DbCart as DB Cart (PostgreSQL)

  User->>UI: Đăng ký tài khoản (form /register/)
  UI->>UserSvc: POST /customers/ {name, email, password}
  UserSvc->>DbUser: INSERT Customer
  DbUser-->>UserSvc: Customer ID
  UserSvc->>Redis: Publish event "customer_created" {customer_id}
  Note over UserSvc,Redis: Sự kiện phát đi bất đồng bộ
  UserSvc-->>UI: 201 Created (Tạo tài khoản thành công)
  UI-->>User: Đăng nhập & chuyển hướng về Home

  %% Async consume
  Redis-.->>CartSvc: Consumer nhận event "customer_created"
  CartSvc->>DbCart: SELECT/INSERT Cart WHERE customer_id=customer_id
  DbCart-->>CartSvc: Cart Created
  Note over CartSvc,DbCart: Giỏ hàng được tạo tự động dưới nền
```

3) SEQUENCE DIAGRAM — THÊM ITEM VÀO CART (CHECK PRODUCT-SERVICE)
================================================================

```mermaid
sequenceDiagram
  autonumber
  actor User as User (Browser)
  participant UI as frontend (UI)
  participant BFF as api-gateway (BFF)
  participant CartSvc as cart-service
  participant ProdSvc as product-service
  participant DbCart as DB Cart

  User->>UI: Click "Thêm vào giỏ"
  UI->>BFF: POST /api/gateway/cart/add-item/
  BFF->>CartSvc: POST /carts/add-item/ {cart_id, book_id, quantity}
  CartSvc->>ProdSvc: GET /products/
  ProdSvc-->>CartSvc: 200 [products list]
  alt book_id not found in products list
    CartSvc-->>BFF: 200 {error: "Book not found"}
    BFF-->>UI: Response error
    UI-->>User: Hiển thị lỗi "Sản phẩm không hợp lệ"
  else book_id is valid
    CartSvc->>DbCart: INSERT CartItem(cart, book_id, quantity)
    DbCart-->>CartSvc: CartItem
    CartSvc-->>BFF: 200 {cart_item}
    BFF-->>UI: 200 Success
    UI-->>User: Cập nhật giỏ hàng thành công
  end
```
