## Chạy nhanh (local, Docker)
1. Cài Docker và Docker Compose.
2. Ví dụ chạy toàn bộ stack trong `AIService02`:

```bash
cd AIService02
docker compose up --build
```

3. Chạy một service đơn lẻ (ví dụ `recommender-ai-service`):

```bash
cd AIService02/recommender-ai-service
pip install -r requirements.txt
python main.py
```

4. Nếu chạy theo microservice dự án khác, mở thư mục tương ứng và dùng `docker-compose.yml` hoặc `requirements.txt` theo hướng dẫn trong thư mục.
